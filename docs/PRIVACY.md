# 隐私与数据安全

## 可以公开的内容

- Skill 指令、脚本和空白模板
- 明确标注为虚构的示例数据
- 不包含个人信息的工作簿截图
- 公开可访问的招聘官网链接

## 不应提交到公开仓库

- 真实姓名、手机号、私人邮箱和微信
- 身份证、住址、生日等身份信息
- 未脱敏的简历和成绩单
- 真实投递日期、面试记录和 Offer 信息
- 内推人或招聘联系人私人信息
- Cookie、Token、API Key、浏览器导出数据
- 登录后取得且无权公开的岗位内容

## 示例数据规则

- 使用虚构企业名称
- URL 使用 `example.com`
- 邮箱仅使用 `example.com`
- 不使用看起来像真实手机号的11位数字
- 在文件中明确写明“虚构示例”

## 本地验证脚本

`validate_tracker_data.py` 只读取本地 JSON，不会联网，也不会上传数据。

`privacy_scan.py` 只进行静态文本扫描，不能替代人工检查。
