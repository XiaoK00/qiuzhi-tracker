# 许可证怎么选

当前仓库已经放入 **MIT License**，适合希望别人自由安装、修改、再发布并进行商业使用的开源项目。

## 使用 MIT 代表什么

别人可以：

- 免费使用
- 修改代码和 Skill
- 重新发布
- 用于商业项目

别人需要保留原许可证和版权声明，但不必把修改后的版本继续开源。

## 以下情况不要直接使用 MIT

- 你准备以后收费授权
- 你不希望别人打包后商业销售
- 你只想公开展示，不允许复制和修改
- 你还没有想清楚授权范围

这时可以先把仓库设为 `Private`，等授权方案确定后再公开。也可以删除 MIT License，但没有许可证的公开仓库并不等于标准开源项目，其他人通常只有查看和 GitHub 平台允许的 Fork 权限。

## 发布前建议

把许可证当成一次正式授权决定。对商业授权、商标和收费模式有明确计划时，应咨询专业人士，而不是只依赖模板说明。
