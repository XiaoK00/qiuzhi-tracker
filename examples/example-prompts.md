# 提示词示例

## 标准规模新建

```text
请使用 qiuzhi-tracker 读取我的简历和求职限制，按标准规模建立真实企业池，
核验当前招聘岗位，分别判断硬性门槛、优先条件、岗位价值、契合指数和当前行动，
运行验证脚本后生成 Excel 求职追踪表。
```

## 轻量探索

```text
请使用 qiuzhi-tracker 按轻量规模探索适合我的企业和岗位。
优先覆盖不同规模和行业，给出可立即执行的岗位清单。
```

## 自定义范围

```text
请使用 qiuzhi-tracker 建立 35 家候选企业，并深度核验至少 10 个岗位。
保留来源等级、核验日期、岗位新鲜度和评分分项。
```

## 更新旧表

```text
请使用 qiuzhi-tracker 更新这份 Excel。
保留我填写的简历版本、投递日期、当前环节、联系人和复盘，
重新检查岗位状态、截止日期、岗位新鲜度和招聘链接，合并重复记录。
```
