# Changelog

本项目遵循语义化版本号。

## [1.0.0] - 2026-08-02

### Added

- 建立 100–150 家真实候选企业池的完整流程
- 深度核验 30–50 家高匹配企业的岗位流程
- 企业池、岗位清单和投递进度的分层结构
- 0–100 契合指数和统一的当前行动
- 招聘来源、状态和日期核验规则
- 标准库数据验证脚本
- 四张主表的精简 Excel 模板
- 增量更新和人工字段保护规则
- GitHub Actions、测试、隐私扫描和 Release 打包工具
- 完全虚构的示例数据、示例工作簿与截图

### Changed

- 企业池从多列尽调结构压缩为 9 列
- 岗位清单压缩为 13 个用户决策字段
- 投递进度仅保留真正准备投递或已经投递的岗位
- 删除重复的推荐层级、处理顺序和是否立即投递字段
