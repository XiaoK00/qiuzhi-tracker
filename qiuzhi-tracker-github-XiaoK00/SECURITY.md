# Security Policy

## 支持版本

| 版本 | 支持状态 |
|---|---|
| 1.x | 支持 |

## 报告安全或隐私问题

请不要在公开 Issue 中提交以下内容：

- 真实简历、联系方式或投递记录
- Cookie、Token、API Key 或登录凭证
- 可识别个人身份的招聘联系人信息
- 可能导致任意代码执行的脚本样例

请通过 GitHub 的私密漏洞报告功能提交安全问题。若仓库尚未启用该功能，请只描述问题类型，不要附带真实敏感数据。

验证脚本本身只读取本地 JSON 文件，不发起网络请求。联网检索由运行 Skill 的 Agent 环境完成。
