# 安装与使用

## Codex 推荐安装方式

```text
$skill-installer install https://github.com/XiaoK00/qiuzhi-tracker/tree/main/skills/qiuzhi-tracker
```

安装后重启 Codex。

## 手动安装

复制仓库中的：

```text
skills/qiuzhi-tracker
```

到：

```text
~/.codex/skills/qiuzhi-tracker
```

## 使用前准备

- 一份可读取的简历
- 招募届别或预计毕业年月
- 目标岗位、行业和城市
- 可接受或排除的销售、轮岗、出差、异地、倒班等条件
- 运行环境必须能联网并创建 Excel

## 最小调用示例

```text
请使用 qiuzhi-tracker Skill，根据这份简历完整建立企业池、核验岗位并生成Excel。
```
