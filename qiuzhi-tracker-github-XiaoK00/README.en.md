# Qiuzhi Tracker


> Maintainer: [XiaoK00](https://github.com/XiaoK00)
Qiuzhi Tracker is a Codex Agent Skill that builds a real company pool, verifies concrete recruiting opportunities, scores job fit from resume evidence, and generates a concise Excel job-search tracker.

The workbook focuses on three decisions: whether the role is open, whether it is worth applying to, and what to do next.

## Main features

- Builds a default pool of 100–150 real companies
- Deep-verifies 30–50 high-fit companies
- Keeps small and medium-sized companies with explicit risk notes
- Separates company-level data, job-level data, and user-maintained application progress
- Produces four concise worksheets
- Validates duplicate records, dates, sources, fit scores, and status/action conflicts
- Protects user-entered application data during updates

## Install in Codex

```text
$skill-installer install https://github.com/XiaoK00/qiuzhi-tracker/tree/main/skills/qiuzhi-tracker
```
